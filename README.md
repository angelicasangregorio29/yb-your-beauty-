# Yb Skincare Landing Page

## Descrizione
Questo progetto è una landing page/mini-store per il brand di skincare Yb, costruita in HTML, CSS e JavaScript vanilla. L’obiettivo è presentare un’identità premium, scientifica e moderna, con pagine dedicate a home, shop, quiz di personalizzazione, scienza del brand e contatti.

## Obiettivo del lavoro
Il progetto è stato portato a uno stato iniziale funzionale e coerente, con una struttura multi-pagina, navigazione stabile, layout responsive e contenuti tematici coerenti con il brand.

## Stack utilizzata
- HTML5
- CSS3
- JavaScript vanilla
- Nessun framework/backend: sito statico pronto per hosting semplice

## Struttura del progetto
- `index.html` — entry page principale
- `home.html` — landing page con hero e bestseller
- `shop.html` — catalogo prodotti con filtri statici
- `quiz.html` — quiz di personalizzazione skincare
- `science.html` — sezione sulla filosofia e ingredienti
- `contact.html` — pagina di contatto
- `style.css` — stili globali e responsive
- `script.js` — logica di navigazione, menu mobile, quiz e CTA

## Lavori svolti
### Fase 1 — Analisi e struttura
- Rilevata la natura del progetto: sito statico senza framework/backend
- Identificate le pagine presenti e la loro coerenza iniziale
- Uniformata la struttura HTML delle pagine principali
- Corretto l’entry point della home e il comportamento della navigazione
- Sistemato il footer e il branding visivo

### Fase 2 — Coerenza visuale e contenuti
- Standardizzati titoli, meta description e struttura semanticamente più pulita
- Aggiornato contenuto testuale in italiano con tono skincare premium
- Aggiunte immagini reali placeholder per i prodotti
- Sistemato il menu mobile e l’accessibilità di base

### Fase 3 — Validazione e controllo qualità
- Verificata la disponibilità delle pagine principali tramite localhost
- Controllato che non ci fossero placeholder evidenti residuali
- Validata la navigazione iniziale e il comportamento main nav
